# BanDNS

</div>

---

> **Учебный проект.** CLI DNS прокси на языке Python для перехвата пакетов и фильтрации по текстовому файлу

## Запуск

1. Скачать .exe файл и положить его в удобную папку (например, на рабочий стол).
2. В ту же папку положить файл со списком заблокированных доменов. Файл должен называться **`domains_list.txt`** — это имя прописано в коде по умолчанию. Если назвать иначе, необходимо будет указать имя при запуске через флаг `--rules`.
3. Открыть консоль (PowerShell / CMD / Terminal) **от имени администратора** в этой папке.
4. Запустить:

````bash
./ban_dns server
````
Сервер запустится на `127.0.0.1:53`

Доменные имена в `domains_list.txt` не будут доходить до вышестоящего DNS сервера.

## Настройка DNS в системе

Чтобы трафик шёл через BanDNS, необходимо указать `127.0.0.1` как предпочитаемый DNS-сервер в настройках сети ОС.

**Windows:** Параметры → Сеть и Интернет → Wi-Fi / Ethernet → Изменить параметры DNS → Вручную → IPv4 → Предпочитаемый DNS: `127.0.0.1`.

## Параметры запуска

| Параметр     | По умолчанию       | Назначение                                         |
|--------------|--------------------|----------------------------------------------------|
| `--host`     | `127.0.0.1`        | Адрес прослушивания                                |
| `--port`     | `53`               | Порт                                               |
| `--upstream` | `8.8.8.8`          | Вышестоящий DNS для незаблокированных запросов     |
| `--rules`    | `domains_list.txt` | Путь к файлу блокировок                            |
